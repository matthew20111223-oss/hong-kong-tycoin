# HONG KONG TYCOON

香港主題、2–20 人即時連線地產棋盤遊戲原型。採用 Node.js + Express + Socket.IO，手機瀏覽器優先設計。

## 本機啟動
1. 安裝 Node.js 18 或以上版本。
2. 在專案資料夾執行 `npm install`
3. 執行 `npm start`
4. 瀏覽器開啟 `http://localhost:3000`

## 讓朋友在線上加入
需要把整個專案部署到支援 Node.js 長連線 / WebSocket 的主機。部署完成後，分享網站網址；房主建立房間，再分享 6 位房間碼。免費主機可能會休眠，正式遊玩建議使用穩定 Node.js hosting。

## iPhone 加入主畫面
Safari 開啟部署後網址 → 分享 → 加入主畫面。

## 目前原型功能
- 房間建立及房間碼加入
- 最多 20 位玩家
- 即時同步玩家、棋盤、資金及事件紀錄
- 40 格香港主題棋盤
- 擲骰、移動、購買地產、租金、稅項、機會卡、公共基金、入獄、房屋及酒店升級
- 破產及最後玩家勝出判定

## 重要說明
這是可部署的遊戲原型，不是已經代你上線的公開網站。要讓不同網絡的 iPhone 真正連線，必須先部署 Node.js 伺服器。現階段未包含帳戶系統、持久化資料庫、斷線重連恢復、完整拍賣/抵押/交易流程及反作弊安全審核。正式公開前應補上伺服器端驗證、資料庫與安全測試。
